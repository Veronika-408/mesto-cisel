# Mesto čísel

Interaktívna stránka z matematiky pre žiakov prímy a sekundy osemročného gymnázia.

Ostrov **Mesto čísel** má zatiaľ jednu otvorenú časť, **Zlomkovú štvrť**. V nej je osem budov a každá ukazuje zlomky v jednej situácii zo života:

| Budova | Téma (ŠkVP, sekunda) |
|---|---|
| Zlomková pekáreň | pojem zlomku, krátenie, rozširovanie |
| Vežové hodiny | zlomok z čísla, sčítanie |
| Hudobná škola | sčítanie a odčítanie |
| Turistický chodník | číselná os, porovnávanie |
| Pizzeria | zmiešané čísla |
| Záhradníctvo | násobenie |
| Limonádový stánok | delenie |
| Veža hlavolamov | súťažné úlohy |

Každá budova má štyri kroky: *Kde to stretneš*, *Pozri bližšie*, *Prečo to platí* a *Úlohy* (od ľahkých po súťažné, s nápovedou a riešením).

Celá stránka je jeden súbor `index.html` a nepotrebuje server. Stačí ju otvoriť v prehliadači alebo zverejniť cez GitHub Pages.
